# Instant, structured design reviews
A Claude skill that offers you actionable design feedback, as if a world-class product designer was sitting next to you. Share a screenshot, a Figma link, or a live URL and get a structured review using the HEROES framework, a six-lens methodology for focused, meaningful UI feedback. Built for solo designers, PMs, developers, and founders who don't always have someone to bounce ideas off, as well as anyone who wants a solid starting point before a live review.

## The HEROES framework
Inspired by [The Laws of Simplicity](https://lawsofsimplicity.com/), the [Six Thinking Hats](https://www.debonogroup.com/services/core-programs/six-thinking-hats/), and [BlaBlaCar's simplification reviews](https://www.youtube.com/watch?v=vPit2SqdaCo), HEROES organizes feedback into six focused lenses to replace unfocused, visuals-heavy critique sessions with actionable, structured reviews that anyone can participate in.

| | Lens | Description |
| :---: | :--- | :--- |
| H | Hide | Hide what isn't essential to reduce cognitive load |
| E | Eliminate | Eliminate what's irrelevant entirely |
| R | Reduce | Reduce redundancy wherever it appears |
| O | Organize | Organize for clarity and hierarchy |
| E | Enchant | Enchant users with moments of delight and trust |
| S | Standardize | Standardize with platform/design system conventions |

#### How it works
Share a screenshot, a Figma link, or a live URL and ask for a design review. Claude will automatically apply the HEROES framework and return structured feedback across the six lenses, closing with a prioritized summary of the top three findings. You can also trigger the skill explicitly by typing:

```sh
/heroes-design-review
```

This skill is actively maintained. Install it once and updates will be pulled automatically in the background, you don't need to do a thing.

#### Designed for UI, not art direction
HEROES is specifically focused on UI and product design. It's not the right tool if you're looking for feedback on art direction, brand identity, illustration, or visual aesthetics. The framework is built around usability, clarity, and convention, not creative expression.
